## 2. ผลการทดสอบระบบ (Quality Assurance & Debugging Report)

> Debugger กรอกคอลัมน์ "ผลการทดสอบจริง" และ "สถานะ" จากการรันจริง

### 2.1 End-to-End

| รหัส | รายการทดสอบ | ขั้นตอน | ผลลัพธ์ที่คาดหวัง | ผลการทดสอบจริง | สถานะ |
| --- | --- | --- | --- | --- | --- |
| TC-01 | วางแผนทริปครบวงจร | สร้างทริป → ค้นหาและบันทึกสถานที่ 3 แห่ง → จัดลงวัน → ดูรายละเอียด | แผนรายวันแสดงสถานที่ตามวันที่จัด | | |
| TC-02 | ค่าใช้จ่ายครบวงจร | ดูประมาณการ → เพิ่ม 3 รายการ → แก้ 1 → ลบ 1 → สรุปงบ | ยอดใช้จริงในสรุปตรงกับรายการที่เหลือ | | |
| TC-03 | ข้อมูลคงอยู่ | ทำ TC-01, TC-02 แล้วปิดและเปิดโปรแกรมใหม่ | ข้อมูลทั้งหมดยังอยู่ครบ | | |
| TC-04 | ประมาณการเปลี่ยนตามข้อมูล | บันทึกสถานที่เพิ่ม 1 แห่ง แล้วดูประมาณการอีกครั้ง | ค่าเข้าชมเพิ่มขึ้นตามจำนวนสถานที่ | | |
| TC-05 | เตือนเกินงบ | ตั้งงบ 1,000 บาท แล้วเพิ่มค่าใช้จ่าย 1,200 บาท | สรุปงบแจ้ง "ใช้จ่ายจริงเกินงบแล้ว 200.00 บาท" | | |

### 2.2 Edge Cases

| รหัส | รายการทดสอบ | สถานการณ์ | ผลลัพธ์ที่คาดหวัง | ผลการทดสอบจริง | สถานะ |
| --- | --- | --- | --- | --- | --- |
| TC-06 | ทริปสั้นลง | ทริป 3 วันมีสถานที่ในวันที่ 3 แก้เป็น 2 วัน | แจ้งว่าย้ายสถานที่ 1 แห่งเป็น "ยังไม่ได้จัดวัน" | | |
| TC-07 | จัดวันเกินจำนวนวัน | ทริป 3 วัน จัดสถานที่ลงวันที่ 5 | แจ้งช่วงวันที่ถูกต้อง และถามซ้ำ | | |
| TC-08 | ไฟล์ฐานข้อมูลเสีย | ปิดโปรแกรม เปิด `data/travel_planner.db` ด้วย Notepad พิมพ์ข้อความทับแล้วบันทึก จากนั้นเปิดโปรแกรม | แจ้งว่าไฟล์เสียหาย ย้ายไฟล์เดิมไว้ และสร้างฐานข้อมูลใหม่ | | |
| TC-09 | ไฟล์ฐานข้อมูลถูกลบระหว่างใช้งาน | เปิดโปรแกรมค้างไว้ ลบไฟล์ `.db` แล้วดูทริปทั้งหมด | ไม่ Crash แจ้งว่าสร้างฐานข้อมูลใหม่ | | |
| TC-10 | ไฟล์ราคาอ้างอิงหาย | เปลี่ยนชื่อ `reference_prices.json` แล้วเปิดโปรแกรม | แจ้งว่าไม่พบไฟล์และใช้ค่าเริ่มต้น ประมาณการยังทำงาน | | |
| TC-11 | ออฟไลน์ทั้งระบบ | ปิด Wi-Fi แล้วสร้างทริป | เลือกบันทึกโดยไม่มีพิกัดได้ และกรอกระยะทางเองได้ | | |
| TC-12 | ค้นหาทริปด้วยคำว่าง | เมนู 3 แล้วกด Enter | แจ้งให้กรอกข้อมูล และถามซ้ำ | | |
| TC-13 | กรองแล้วไม่เจอ | กรองค่าใช้จ่ายหมวดที่ไม่มีรายการ | แจ้ง "ไม่มีรายการที่ตรงเงื่อนไข" | | |
| TC-14 | รหัสที่ไม่มีอยู่ | เปิดทริปรหัส `999` / แก้ค่าใช้จ่ายรหัส `999` | แจ้ง "ไม่พบ..." แล้วกลับเมนู | | |
| TC-15 | ค่าสุดขอบ | จำนวนคน `50` และ `51`, จำนวนเงิน `10000000` และ `10000001` | รับค่าแรก ปฏิเสธค่าที่สอง | | |
| TC-16 | ยกเลิกระหว่างแก้ไข | แก้ไขทริป พิมพ์ `cancel` กลางทาง แล้วดูรายละเอียด | ข้อมูลทริปยังเป็นค่าเดิม | | |
